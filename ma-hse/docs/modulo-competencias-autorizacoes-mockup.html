nota
A quinta coluna, "Espaços confinados", não estava na lista inicial. Está aqui de propósito: as colunas são geradas a partir da tabela CompetenceType, não fixadas no código. Acrescentar um tipo de competência é criar um registo de master data — não uma migração de base de dados nem uma alteração ao componente da matriz. É a razão estrutural mais importante desta proposta.

alteração
Seleção múltipla, em vez de um a um. A inscrição inicial de uma fábrica são dezenas de trabalhadores; um a um torna o arranque impraticável.
decisão 2.2
A área é atribuída aqui, não herdada. EmployeeDirectory.dept é texto livre e não serve para encaminhar alertas; o areaId aponta para uma Area real do Master Data. Quando o texto casa com o nome de uma área, o select vem pré-selecionado; quando não casa — ou está vazio — fica a amarelo à espera de escolha. É o único momento em que alguém está a olhar de propósito para aquele trabalhador.
